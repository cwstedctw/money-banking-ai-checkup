怎麼用 / How to use

  1. 主線：用你的 AI agent 開資料夾。下載課程資料夾 ZIP、解開，用 Antigravity（File → Create Project → Add Folder）、ChatGPT 桌面版的 Codex（檔案 → 新增專案 → 新增資料夾）或 Claude 桌面版（Code 分頁 → 開啟資料夾）打開 kit/zh，貼一句「請照這個資料夾的 AGENTS.md 做完 任務.md 的任務一」。它會自己抓財報、做出每格有頁碼的表、列出比率算式。
    Main route: open the folder with your AI agent. Unzip the course folder and open kit/en in Antigravity (File → Create Project → Add Folder), ChatGPT desktop's Codex (File → New project → add the folder) or Claude desktop (Code tab → Open folder); paste "Follow AGENTS.md in this folder and complete Task 1 in TASK.md".
  2. 沒有 agent？下載上面的財報，上傳到 ChatGPT 或 Claude 網頁，貼提示語 ③。
    No agent? Download the report above, upload it to ChatGPT or Claude on the web, paste Prompt ③.
  3. 拿到表之後，五個比率自己再算一次（體檢表範本會算）——agent 算得快，核對是你的事。
    Then recompute the five ratios yourself (the template does it) — the agent is fast, checking is your job.
  4. 抽三格回原文查：單位、年度欄、合併或個體。
    Spot-check three cells against the original: units, year column, consolidated or not.
  5. 交作業附揭露句：「本作業使用＿＿（AI 工具）協助＿＿（做了什麼）；數字已由本組對照原文核對。」
