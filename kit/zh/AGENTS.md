# 這個資料夾的規則（給 AI agent 看）

用你的人是「貨幣銀行學」的大學生，正在課堂上第一次用 agent 讀一家銀行的財報。做完以後，他會自己挑三格翻回 PDF 核對、再用計算機把比率算一次，所以你交出的每個數字都要讓他翻得回去。

跟使用者說話一律用繁體中文、台灣用語（例：資料、預設、軟體）。

## 資料從哪裡來

- 只用 `data/` 裡的財報。原因：這堂課練的是「每個數字指回原文」；用你記得的數字或別的網站，學生就沒辦法核對。
- `data/` 裡還沒有 PDF 時，照 `data/README.md` 列的官方網址下載到 `data/`，算 sha256 跟表上那一欄比。下載、算 sha256、存進 `data/` 這三步不用先問使用者，直接做。
- sha256 對不上、下載失敗、或網址打不開：停下來，告訴使用者是哪個檔、看到什麼錯誤，請他自己用瀏覽器從同一個網址下載、放進 `data/` 再叫你繼續。不要改用其他網站的版本，因為頁碼和數字可能不一樣。
- 任務三是使用者自己挑的銀行，`data/README.md` 沒有那兩份的 sha256：用使用者放進 `data/` 的檔，或他給的官方網址；把網址和下載日期寫在成品裡就好。

## 每個數字要附什麼

- 檔名、**PDF 第幾頁**（從 1 起算的實體頁）、那一頁印的頁碼（有的話）、**科目名稱原文**（照財報的字，一個字都不改寫）。
- 單位照原文寫清楚（新臺幣千元）；年度欄寫清楚（114 年 12 月 31 日，不是 113 年）；寫明是合併還是個體報表。原因：抄錯欄、把千元當元、拿到金控報表，是這份作業最常見的三種錯。

## 每一句標來源

每一句話後面標一個：

- **（表上）**：數字或文字直接出自財報，附得出頁碼。
- **（算的）**：由表上數字算出來的，算式寫在旁邊。
- **（推論）**：表上沒有、是你判斷或假設的（例如「銀行會先賣證券」「存戶為什麼提款」）。

原因：課堂要學生分辨哪句有出處、哪句是 AI 推的；你先標好，他才有東西可以對。

## 比率

- 每個比率寫「分子＝哪一格、分母＝哪一格」。
- 任務裡寫「比率我自己算」時，只列算式、不給結果；使用者算完來問你，再把你算的結果（%，小數兩位）給他對照。原因：先讓學生自己動手，對照時差一格就是線索。

## 找不到就說找不到

- 任務要的數字在 `data/` 的檔裡找不到，就在那一格寫「找不到」，並告訴使用者你找過哪幾頁；不要用其他來源補，也不要猜。
- 任務的意思不清楚（例如不知道該用哪一欄）就停下來問一句，再繼續。

## 成品

- 任務一寫 `成品/體檢表.md`，任務二寫 `成品/壓力測試.md`，任務三寫 `成品/回家-兩家銀行.md`；老師示範版的檔名寫在 `任務-老師示範.md`。
- 讀 PDF 需要的 Python 套件（例如 pymupdf、pypdf）可以直接用 `pip install --user` 裝，不用先問；需要系統管理員權限的東西不要裝，改告訴使用者。
- 不要改 `data/` 以外、`成品/` 以外的檔；不要把任何檔上傳到網路上。原因：這是學生自己的電腦，資料夾外的東西不是這次作業的範圍。

## 個資

這個資料夾只有銀行公開的財報。使用者如果貼了同學的姓名、學號或成績，提醒他刪掉，不要寫進任何檔案。
