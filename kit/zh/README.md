# 課程資料夾（中文場）：用你的 AI agent 幫彰化銀行做體檢

> 貨幣銀行學 AI 第二輪。網站：https://cwstedctw.github.io/money-banking-ai-checkup/
> 這個資料夾給 AI agent（會自己開檔、下載、寫檔的 AI）打開。它照 `AGENTS.md` 的規則，把彰化銀行的財報做成一張每格都有頁碼的體檢表。**核對是你的事**：它做完，你要自己抽三格、自己再算一次比率。

## 1. 下載這個資料夾

到網站按「下載課程資料夾（ZIP）」，或直接開 https://github.com/cwstedctw/money-banking-ai-checkup/archive/refs/heads/main.zip
解開後，你要打開的是裡面的 `kit/zh` 這一夾（不是整包）。

## 2. 用你的 agent 打開 `kit/zh`

有哪個就用哪個：

| agent | 怎麼開這個資料夾 |
|---|---|
| Antigravity | File → Create Project → Add Folder → 選 `kit/zh` → Next（舊版介面是 File → Open Folder） |
| ChatGPT 桌面版（Codex） | 檔案 → 新增專案 → 按「新增」選資料夾 `kit/zh` → 建立專案 → 信任資料夾 |
| Claude 桌面版 | Code 分頁 → 開啟資料夾 → 選 `kit/zh` |

### 暖身：課文整理（提示語 ①，課堂第 2–9 分鐘）

把你自己的課本第 9 章電子檔（PDF）放進這個資料夾，貼投影片第 4 頁的提示語 ①（網站的「提示語①–⑤」頁有複製鈕）。它會畫章節地圖、出五題、每題附頁碼；你照頁碼翻回課本對一題。

只有紙本課本：用手機拍其中兩三頁，把照片放進這個資料夾（或上傳到聊天版）也可以，它會標書上印的頁碼。

課本是有著作權的書：檔案只放在你自己的電腦，不要傳給別人、不要放上網路；做完可以把它從資料夾拿走。

## 3. 貼這一句

> 請照這個資料夾的 AGENTS.md 做完 任務.md 的任務一

它問你「可不可以下載／執行指令」時，看清楚是 `data/README.md` 上的彰化銀行網址再按允許。ChatGPT 桌面版會問一次（按「執行一次」）；Antigravity 每下載一份問一次（選「Yes, allow this time」再按 Submit）。整個任務一大約 3 到 5 分鐘。

## 4. 你應該看到

1. 它先看 `data/` 有沒有財報；沒有就照 `data/README.md` 下載兩份 PDF、對 sha256。
2. 它讀財報 PDF 第 1 頁（紙本頁碼 8）的合併資產負債表。
3. 出現 `成品/體檢表.md`：八個數字，每格有 PDF 頁碼和科目原文、單位寫千元；五個比率只列算式。

下載不了：它會停下來告訴你。用瀏覽器開 `data/README.md` 裡的網址，把 PDF 存進 `data/`（檔名照表上），再跟它說「繼續」。

## 5. 做完你自己要做的兩件事

1. **抽三格**：打開 PDF 到它說的那一頁，核對單位、年度欄（114 年，不是 113 年）、合併或個體。
2. **比率再算一次**：用計算機或網站上的體檢表範本（`體檢表範本.xlsx`）算五個比率，再問它「你算的結果是多少」，兩邊對照——差一格就是線索。

接著貼「接著做 任務.md 的任務二」做壓力測試；回家做任務三（換兩家銀行）。

## 6. 沒有 agent，或打不開：聊天版

用 ChatGPT 或 Claude 網頁版：從網站下載彰化銀行財報（10 頁那份）上傳，把 `任務.md` 任務一那一框整段貼上。比率自己算。
